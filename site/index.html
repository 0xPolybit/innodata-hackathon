TaskFactory

Chart questions with answers you can check by machine.

TaskFactory makes chart questions that have known exact answers, then checks each one with plain code instead of an AI model. Every task either passes all the checks or is listed with the check it failed. The same checks let you test free AI models against a fixed set of questions and see how many they get right.

  • Generated charts and questions, with exact answers in the data.
  • Seven automated checks per task: no model and no API key involved.
  • A repeatable run: the same seed and code give the same tasks.
